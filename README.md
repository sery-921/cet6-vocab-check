# 六级词汇通关（测试版）

纯静态网站，可直接部署到 GitHub Pages。练习进度保存在当前浏览器的 localStorage，不会跨设备自动同步。

## 上传到 GitHub Pages

1. 新建一个 GitHub 仓库。
2. 将本目录的 `index.html`、`app.js`、`style.css`、`data` 文件夹、`.nojekyll` 和 `README.md` 上传到**仓库根目录**。若下载的是 ZIP，请先解压，上传解压后的文件；不要只上传 ZIP。
3. 在仓库的 **Settings → Pages** 中，选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`，保存。
4. 等待 GitHub Pages 给出网站地址，再打开检查词表数量、搜索和进度导入。

## 从本地预览迁移进度

先在本地预览点击“备份进度”，保存 `cet6-progress.json`。网站上线后，在“数据说明”点击“导入进度备份”，选择该 JSON 文件。这个备份文件**不要上传到公开仓库**。

## 数据范围

- 2016 版考纲：当前按带 ★ 的词条行练习，1,263 条；一行可能含多个词形。
- 2026 年 6 月第一套：18 条经人工核对的短例句。未包含真题 PDF、答案全文或音频。
- 本地预览试填 30 条考纲主词的常见义，其中 18 条另有真题句中义与词性。其余词条仍显示“释义待补充”；词频统计尚未完成。
