# 六级词汇通关

根据《全国大学英语四、六级考试大纲（2016年修订版）》带 ★ 的词条制作，包含 1,263 条主词。主词有词性和常见中文义；另有 18 条已核对的真题短例句。

“聊天关卡”目前有 20 个原创话题，每关 8 个考纲词。话题按“继续练／未练过／已练过”展示；完成过且正在重练的话题会同时出现在“继续练”和“已练过”。已完成话题再次点开时先显示上次结果，只有点“再练一遍”才开始新一轮。练习位置保存在浏览器本地。词汇判断与聊天记录一起包含在网站的“备份进度”文件中，旧版备份也可导入。

前 30 条释义为人工试填，其余主要根据 [ECDICT](https://github.com/skywind3000/ECDICT) 英汉词典自动匹配，仍需逐条校对。ECDICT 使用 MIT 许可证，全文见 [ECDICT-LICENSE.txt](./ECDICT-LICENSE.txt)。

把本文件夹中的内容放在 GitHub 仓库根目录即可通过 GitHub Pages 发布。不要上传个人导出的 `cet6-progress.json`。
