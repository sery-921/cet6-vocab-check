# 六级词汇通关

根据《全国大学英语四、六级考试大纲（2016年修订版）》带 ★ 的词条制作，包含 1,263 条主词。主词有词性和常见中文义；另有 18 条已核对的真题短例句。

“聊天关卡”目前有两个原创话题，每关 8 个考纲词。话题按“继续练／未练过／已练过”分类；练习位置保存在浏览器本地。词汇判断与聊天记录一起包含在网站的“备份进度”文件中，旧版备份也可导入。

前 30 条释义为人工试填，其余主要根据 [ECDICT](https://github.com/skywind3000/ECDICT) 英汉词典自动匹配，仍需逐条校对。ECDICT 使用 MIT 许可证，全文见 [ECDICT-LICENSE.txt](./ECDICT-LICENSE.txt)。
